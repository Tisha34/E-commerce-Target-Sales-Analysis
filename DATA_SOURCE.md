## Dataset

This project uses the e-Commerce (Target) Sales Dataset from Kaggle.

[Download the dataset here](https://www.kaggle.com/datasets/devarajv88/target-dataset)

### Tables needed (6 CSV files)
- customers.csv
- orders.csv
- order_items.csv
- products.csv
- payments.csv
- sellers.csv
- geolocation.csv

Import all 7 files into MySQL before running the SQL queries.
